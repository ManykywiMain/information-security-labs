# Лабораторна робота 1. Шифри заміни та перестановки

Навчальна реалізація чотирьох класичних шифрів для курсу «Програмні технології захисту інформації».
**Не використовувати для захисту реальних даних** — для цього є AES-GCM через перевірені бібліотеки.

| Алгоритм | Назва в CLI | Ключ |
|---|---|---|
| Проста одноалфавітна підстановка | `substitution` | ключове слово (33 літери = готова таблиця) |
| Шифр Віженера | `vigenere` | ключове слово з літер алфавіту |
| Блокова перестановка | `block` | перестановка, напр. `3 2 5 1 4` або компактно `32514` |
| Вертикальна перестановка | `columnar` | порядок читання стовпців, напр. `3 1 4 2` або `3142` |

## Вимоги

* Python 3.9 або новіший (перевірено на 3.13);
* **зовнішніх залежностей немає** — лише стандартна бібліотека (`unittest`, `argparse`).

## Запуск

З папки `lab1`:

```bash
python -m cipherlab1 --help
python -m cipherlab1 rules                         # правила підготовки тексту

python -m cipherlab1 encrypt --algo vigenere --key КЛЮЧ --text "СЛАВА УКРАЇНІ"
python -m cipherlab1 decrypt --algo vigenere --key КЛЮЧ --text "ВЬЮЩК ДЇККЧЛД"

# файли UTF-8
python -m cipherlab1 encrypt --algo substitution --key БЕЗПЕКА --input data/own_text.txt --output enc.txt
python -m cipherlab1 decrypt --algo substitution --key БЕЗПЕКА --input enc.txt --output dec.txt

# блокова перестановка у режимі letters-only (як у контрольному векторі)
python -m cipherlab1 encrypt --algo block --key "3 2 5 1 4" --mode letters-only --text "СЛАВА УКРАЇНІ"

# вертикальна: шифрування виводить кількість доданих символів, її передають у --pad
python -m cipherlab1 encrypt --algo columnar --key "3 1 4 2" --text "КРИПТО"
python -m cipherlab1 decrypt --algo columnar --key "3 1 4 2" --pad 2 --text "..."
```

Помилка (некоректний ключ, символ, файл) дає повідомлення в `stderr` і код завершення `1`;
некоректні аргументи — код `2`. Результат у файл записується атомарно: у разі помилки
частково записаного файлу не лишається, наявний вихідний файл не змінюється.

Експеримент на власному тексті (300–500 літер): `python run_experiment.py`
(результат у `results/experiment.json` та `results/experiment.txt`).

## Тести

```bash
python -m unittest discover -v
```

53 тести: 4 контрольні вектори (пряма і зворотна операції), зворотність для 12 повідомлень ×
4 алгоритми × 2 режими, генеративний тест із фіксованим зерном (400 випадкових ключів і текстів),
границі, українські літери Ґ Є І Ї, форматування, доповнення, негативні сценарії, UTF-8 файли, CLI.

## Структура

```
cipherlab1/
  textprep.py      алфавіт, NFC, регістр, перевірка символів, режими preserve / letters-only
  keys.py          перевірка ключових слів і перестановок, обернена перестановка
  substitution.py  побудова і перевірка таблиці, шифрування/розшифрування
  vigenere.py      шифр Віженера (ключ просувається лише на літерах)
  permutations.py  блокова та вертикальна перестановки
  service.py       encrypt/decrypt: ключ -> підготовка тексту -> алгоритм
  fileio.py        читання UTF-8, атомарний запис
  cli.py           командний рядок (encrypt, decrypt, rules)
tests/             автоматизовані тести
data/own_text.txt  власний текст для експерименту
run_experiment.py  відтворюваний експеримент
```

Криптографічна логіка (`substitution`, `vigenere`, `permutations`) не залежить від введення-виведення.

## Рішення за специфікацією

* Алфавіт (m = 33): `АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ`.
* Текст: NFC → верхній регістр → перевірка. Допустимі літери алфавіту, пробіли/переноси, цифри,
  розділові знаки; латиниця, російські літери, емодзі тощо відхиляються з номером позиції.
* `preserve` (типово) зберігає всі допустимі символи, тому операція зворотна; `letters-only`
  залишає лише літери (незворотний щодо пробілів, потрібен для вектора блокової перестановки).
* Підстановка й Віженер змінюють лише літери; у Віженера сторонні символи не просувають ключ.
* Блокова перестановка: неповний останній блок не змінюється.
* Вертикальна: останній рядок доповнюється символом `_`; кількість доданих символів повертається
  окремо, за нею ж вилучається при розшифруванні (справжні `_` у кінці тексту не губляться).
  Розшифрування без `--pad` — помилка.
* Ключ підстановки з 33 літер (наприклад, алфавіт навпаки) є готовою таблицею.

## Обмеження

Усі чотири шифри зберігають структуру або частоти тексту, мають малий простір ключів і не
забезпечують автентичність повідомлення. Тестові дані — лише вигадані.
