# Лабораторна робота 2. Квадрат Полібія та шифр Гронсфельда

Навчальна реалізація трьох режимів для курсу «Програмні технології захисту інформації»:
координатний шифр Полібія, циклічний зсув за рядками квадрата та шифр Гронсфельда — для
українського та латинського наборів символів.
**Не використовувати для захисту реальних даних** — для цього є AES-GCM через перевірені бібліотеки.

| Режим | Назва в CLI | Ключ |
|---|---|---|
| Полібій, координати | `polybius-coordinates` | ключове слово |
| Полібій, зсув за рядками | `polybius-row-shift` | ключове слово |
| Гронсфельд | `gronsfeld` | рядок цифр (напр. `31415`, `0517`) |

Мова обирається явно: `--lang ua` або `--lang en`. Автоматичного вгадування мови немає.

## Вимоги

* Python 3.9 або новіший (перевірено на 3.13);
* **зовнішніх залежностей немає** — лише стандартна бібліотека (`unittest`, `argparse`).

## Запуск

З папки `lab2`:

```bash
python -m polybiuslab2 --help
python -m polybiuslab2 rules                                   # правила обробки
python -m polybiuslab2 square --lang ua --key БЕЗПЕКА          # показати квадрат 6 на 6

python -m polybiuslab2 encrypt --algo polybius-coordinates --lang ua --key БЕЗПЕКА --text СЛАВА
python -m polybiuslab2 decrypt --algo polybius-coordinates --lang ua --key БЕЗПЕКА --text "44 35 16 21 16"
python -m polybiuslab2 encrypt --algo polybius-row-shift --lang en --key SECURITY --text HELLO
python -m polybiuslab2 encrypt --algo gronsfeld --lang ua --key 31415 --text "СЛАВА УКРАЇНІ"

# координатний режим не приймає пробіли; їх видаляють окремою видимою операцією
python -m polybiuslab2 encrypt --algo polybius-coordinates --lang ua --key БЕЗПЕКА \
    --text "СЛАВА УКРАЇНІ" --strip-spaces --show-square

# файли UTF-8
python -m polybiuslab2 encrypt --algo gronsfeld --lang ua --key 0517 \
    --input data/own_text_ua.txt --output enc.txt
python -m polybiuslab2 decrypt --algo gronsfeld --lang ua --key 0517 --input enc.txt --output dec.txt
```

Помилка (некоректний ключ, токен, символ, файл) дає повідомлення в `stderr` і код `1`;
некоректні аргументи — код `2`. Результат у файл записується атомарно: у разі помилки
частково записаного файлу не лишається, наявний вихідний файл не змінюється.

Експеримент на власних текстах: `python run_experiment.py`
(результат у `results/experiment.json` та `results/experiment.txt`).

## Тести

```bash
python -m unittest discover -v
```

67 тестів: 6 контрольних векторів (пряма і зворотна операції), квадрати для обох мов, координати
(перший/останній рядок, `11`, `66`, некоректні токени), циклічний перехід 6 → 1, літери Ґ Є І Ї та
A Z, ключі Гронсфельда (початковий нуль, `9`, довгий, порожній, лише нулі), форматування,
зворотність (детермінована та генеративна з фіксованим зерном: 600 випадкових ключів і текстів),
UTF-8 файли, CLI.

## Структура

```
polybiuslab2/
  alphabets.py    набори символів і явний вибір мови
  textprep.py     NFC, верхній регістр, видалення пробільних символів (окрема операція)
  square.py       побудова й перевірка квадрата 6 на 6, прямі та обернені відображення
  coordinates.py  координатний режим, суворий розбір токенів
  row_shift.py    циклічний зсув за рядками
  gronsfeld.py    шифр Гронсфельда, перевірка цифрового ключа
  service.py      encrypt/decrypt: алгоритм, мова, ключ -> обробка
  fileio.py       читання UTF-8, атомарний запис
  cli.py          командний рядок (encrypt, decrypt, square, rules)
tests/            автоматизовані тести
data/             власні тексти для експерименту
run_experiment.py відтворюваний експеримент
```

Таблиці пошуку (символ → координата і назад) будуються один раз для квадрата, обробка тексту
лінійна відносно його довжини.

## Рішення за специфікацією

* Квадрат: ключове слово → NFC → верхній регістр → перевірка символів → унікальні символи за
  першою появою → решта базового набору (літери, потім цифри) → 6 рядків по 6.
  Український набір: 33 літери + `0 1 2`; латинський: 26 літер + `0–9`.
* Координати: «рядок, потім стовпець», нумерація з 1, токени через один пробіл. Розшифрування
  відхиляє будь-який токен, що не є двома цифрами 1–6, порожній токен (подвійний пробіл),
  одинарну цифру і сторонній текст; кінцевий перенос рядка з файлу токеном не вважається.
* Режим `polybius-coordinates` (strict) приймає лише символи квадрата; пробіли — помилка з
  підказкою `--strip-spaces`, яка виводить кількість видалених символів.
* `polybius-row-shift`: символи поза квадратом зберігаються. Увага: в українському квадраті
  є лише цифри `0 1 2`, тому вони зсуваються, а `3–9` лишаються як є.
* Гронсфельд: ключ — рядок (початкові нулі зберігаються), не порожній, без нецифрових
  символів (лише ASCII `0–9`) і не лише з нулів. Змінюються лише літери вибраного алфавіту
  (`m = 33` або `26`); пробіли, цифри, знаки та літери іншого алфавіту не змінюються
  й не просувають ключ.
* Верхній регістр застосовується лише до підтримуваних символів.

## Примітка щодо методички

У тестових вимогах серед некоректних токенів названо `61`. За правилом «два символи від 1 до 6»
і за самим квадратом це допустима клітинка (рядок 6, стовпець 1: `Ь` для `БЕЗПЕКА`), а шифрування
саме видає такі токени. Тому `61` приймається, а як аналоги некоректних перевіряються `00`, `17`,
`67`, `07`, `71`.

## Обмеження

Координатний запис зберігає частоти символів, зсув за рядками — проста підстановка, Гронсфельд із
коротким ключем має малий простір зсувів; жоден режим не забезпечує автентичність. Тестові дані —
лише вигадані.
